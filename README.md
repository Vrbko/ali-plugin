# AliExpress Bundle Deal Filter

This Browser extension hides products labeled as **"Bundle Deals"** on AliExpress, helping you browse more efficiently. Tested on Chrome and Brave.

## 🛠 Features

- Automatically removes product cards containing "Bundle deals"
- Only runs on pages within `aliexpress.com`
- Lightweight and simple to use

---

## 🚀 How to Install

1. **Download or Clone this Repo**
2.	**Open Browser and go to:**
- chrome://extensions/
- brave://extensions/
3.	**Enable Developer Mode**
(Top right corner toggle)
4.	**Click “Load unpacked”**
Select the folder where you cloned/downloaded the extension.
5.	**The extension is now active! 🎉**
Visit any AliExpress page and products labeled with “Bundle deals” will be removed automatically.
